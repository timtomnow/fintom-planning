# Icons Needed

Place the following PNG files in this directory. Once present, the app will use them as its PWA icon on home screens, splash screens, and the browser install prompt.

| File | Size | Purpose |
|---|---|---|
| `icon-192.png` | 192 × 192 px | Standard PWA icon — Android home screen, Chrome/Edge install prompt |
| `icon-512.png` | 512 × 512 px | High-res PWA icon — splash screen, app switcher |
| `icon-maskable-512.png` | 512 × 512 px | Android adaptive icon — use the same design but pad the logo to ~80% of the canvas so the outer 20% can be safely cropped to any shape (circle, squircle, rounded square, etc.) |
| `apple-touch-icon.png` | 180 × 180 px | iOS home screen icon — shown when "Add to Home Screen" in Safari |

**Design recommendation:** solid `#2563eb` background (the app accent colour) with a white "FT" monogram or your logo centred on it. All four files can use the same artwork — only `icon-maskable-512.png` needs the extra safe-zone padding.
